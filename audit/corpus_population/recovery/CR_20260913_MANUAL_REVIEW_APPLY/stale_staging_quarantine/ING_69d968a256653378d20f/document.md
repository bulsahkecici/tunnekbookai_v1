## DEFINITION OF 'SQUEEZING'

- ■ Using standard shotcrete support, reasonable range of ground parameters, and running a Monte Carlo simulation, Radocnic determined a critical oberburden for closed linings
- ■ This relation can be used for a first assessment, if closed lining is feasible
- ■ In case the critical overburden is exceeded, type of lining should be changed to ductile system

## CONCLUSION

- ■ When dealing with large displacements, linings have to be designed with great care
- ■ It is important that lining provides controlled build up of resistance during deformation to prevent lining failure
- ■ At the same time, lining capacity should be utilized optimally throughout the whole deformation process
- ■ All support elements have to be compatible with developing strains
